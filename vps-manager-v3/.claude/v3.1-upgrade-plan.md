## 📋 新功能需求

### 1. 哪吒探针 API 集成

**目标**: 自动从哪吒探针获取 VPS 配置和状态信息

**API 端点**:
- `GET /api/v1/server/list` - 获取服务器列表
- `GET /api/v1/server/{id}` - 获取服务器详情

**获取数据**:
- 服务器名称
- CPU 型号和核心数
- 内存大小
- 硬盘大小
- 网络流量
- 在线状态
- 到期时间（需通过备注或自定义字段）

**认证方式**:
- Bearer Token
- 在请求头添加: `Authorization: Bearer YOUR_TOKEN`

### 2. 性价比排行系统

**替代原有的"趋势可视化"功能**

**性价比评分公式**:
```
性价比得分 = (CPU性能分 × 0.3 + 内存分 × 0.25 + 硬盘分 × 0.15 + 网络分 × 0.1 + 价格分 × 0.2)

其中:
- CPU性能分 = (核心数 × CPU基准分) / 日价格
- 内存分 = 内存GB / 日价格
- 硬盘分 = 硬盘GB / 日价格
- 网络分 = 带宽Mbps / 日价格
- 价格分 = 1 / 日价格 (归一化)
```

**展示维度**:
1. 综合性价比排行
2. CPU 性价比排行
3. 内存性价比排行
4. 存储性价比排行
5. 带宽性价比排行

## 🎯 性价比计算详解

### CPU 性价比计算

```javascript
function calculateCPUScore(vps) {
  const dailyPrice = vps.totalCost / getDaysByCycle(vps.cycle);
  const cpuPerformance = vps.specs.cpu.cores * vps.specs.cpu.baseScore;
  return cpuPerformance / dailyPrice;
}
```

### 内存性价比计算

```javascript
function calculateMemoryScore(vps) {
  const dailyPrice = vps.totalCost / getDaysByCycle(vps.cycle);
  return vps.specs.memory.size / dailyPrice;
}
```

### 存储性价比计算

```javascript
function calculateStorageScore(vps) {
  const dailyPrice = vps.totalCost / getDaysByCycle(vps.cycle);
  const storageMultiplier = vps.specs.storage.type === 'NVMe SSD' ? 1.5 :
                           vps.specs.storage.type === 'SSD' ? 1.2 : 1.0;
  return (vps.specs.storage.size * storageMultiplier) / dailyPrice;
}
```

### 综合性价比计算

```javascript
function calculateOverallScore(vps) {
  const cpuScore = calculateCPUScore(vps);
  const memoryScore = calculateMemoryScore(vps);
  const storageScore = calculateStorageScore(vps);
  const networkScore = calculateNetworkScore(vps);
  const priceScore = calculatePriceScore(vps);

  // 加权平均
  return (
    cpuScore * 0.3 +
    memoryScore * 0.25 +
    storageScore * 0.15 +
    networkScore * 0.1 +
    priceScore * 0.2
  );
}
```
