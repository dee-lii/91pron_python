## 🎯 技术亮点

### 架构设计
- **模块复用**: 完全继承原项目 `calculator.js` 计算核心
- **前后端分离**: Express 提供 API，前端独立运行
- **单页面应用**: 无需构建工具，一个 HTML 文件包含所有功能
- **无状态设计**: 无数据库，localStorage 本地存储

### 用户体验
- **渐变色设计**: 统一视觉风格（#667eea → #764ba2）
- **卡片布局**: 清晰的信息层次
- **交互反馈**: 悬停效果、状态徽章、加载提示
- **响应式设计**: 桌面端和移动端友好

### 性能优化
- **CDN 加载**: Chart.js 从 CDN 加载（无需打包）
- **汇率缓存**: 1 小时缓存 + 降级缓存
- **Alpine 镜像**: Docker 镜像仅约 50MB
- **懒加载**: 图表按需渲染

- **本地存储**: 所有数据存储在浏览器，不上传服务器
- **定期备份**: 建议每月导出 JSON 备份
- **隐私保护**: 无用户跟踪，无数据收集
