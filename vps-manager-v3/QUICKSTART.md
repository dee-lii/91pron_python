# 快速启动指南

## 1. 启动服务

```bash
# 确保已安装依赖
npm install

# 启动后端服务
npm start
```

服务启动后会显示：
```
🚀 VPS Manager v3.0 启动成功！
📍 访问地址: http://localhost:3000
🔧 环境: development
```

## 2. 访问应用

在浏览器中打开：
```
http://localhost:3000/index.html
```

## 3. 快速体验

### 添加第一个 VPS

1. 点击右上角"➕ 添加 VPS"按钮
2. 填写信息：
   - VPS 名称：阿里云香港 1C2G
   - 服务商：阿里云
   - 价格：99
   - 货币：CNY
   - 付款周期：年付
   - 购买日期：选择一个日期
   - 备注：测试服务器（可选）
3. 点击"保存"

### 查看趋势图

1. 切换到"📈 趋势可视化"标签
2. 查看统计卡片（VPS 总数、总投入、剩余价值、平均使用率）
3. 观察饼图（已消耗 vs 剩余价值）
4. 观察柱状图（VPS 对比）
5. 在下拉菜单选择 VPS，查看价值衰减趋势

### 续费决策

1. 切换到"🤔 续费决策"标签
2. 填写当前 VPS 信息：
   - 当前价格：99
   - 当前货币：CNY
   - 当前周期：年付
   - 购买日期：选择你的购买日期
3. 填写续费信息：
   - 续费价格：120
   - 续费货币：CNY
   - 续费周期：年付
   - 折扣百分比：20（可选）
4. 点击"计算决策"

系统会智能分析并给出建议：
- ✅ 建议续费当前服务
- 💡 建议重新购买新服务
- 🚨 建议先用完现有服务

### 数据管理

**导出数据**：
- 点击右上角"📤 导出数据"
- 自动下载 JSON 文件

**导入数据**：
- 点击右上角"📥 导入数据"
- 选择之前导出的 JSON 文件
- 确认导入

## 4. 主要功能说明

### 批量管理
- ✏️ 编辑：点击 VPS 卡片右上角的编辑按钮
- 🗑️ 删除：点击删除按钮（会有确认提示）
- 排序：使用列表上方的排序按钮

### 趋势可视化
- 所有图表自动更新
- 支持响应式设计，移动端友好
- 鼠标悬停查看详细数据

### 续费决策
- 支持多货币自动转换
- 考虑折扣因素
- 给出明确建议和节省金额

## 5. 常见问题

**Q: 数据保存在哪里？**
A: 数据保存在浏览器的 localStorage 中，清除浏览器数据会丢失。建议定期导出备份。

**Q: 支持哪些货币？**
A: 支持 CNY、USD、EUR、GBP、JPY 等主流货币。

**Q: 汇率从哪里获取？**
A: 从后端服务的多个汇率 API 源获取，自动降级保证可用性。

**Q: 可以管理多少个 VPS？**
A: 理论上没有限制，但受浏览器 localStorage 容量限制（通常 5-10MB）。

**Q: 支持移动端吗？**
A: 是的，应用采用响应式设计，支持移动端浏览器。
