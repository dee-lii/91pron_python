# 📝 网站文字修改指南

## 🎯 概述

这个网站是一个**高度压缩的 React 应用**，所有文字都在 JavaScript 文件中。由于代码已经被压缩（minified），直接修改会比较困难。

---

## 🔧 修改方法

### 方法 1：使用文本编辑器搜索替换（推荐）⭐

#### 步骤：

1. **打开 JavaScript 文件**
   ```bash
   使用文本编辑器打开：
   /Users/deelii/code/mr-pandas-portfolio/assets/index--Xm2hwTR.js
   ```

2. **搜索要修改的文字**
   - 使用编辑器的"查找"功能（通常是 Cmd+F 或 Ctrl+F）
   - 搜索你想修改的文字，例如：`welcome` 或 `portfolio`

3. **替换文字**
   - 使用"查找和替换"功能（Cmd+H 或 Ctrl+H）
   - 输入旧文字和新文字
   - 点击"全部替换"或逐个替换

4. **保存文件**

5. **刷新浏览器**
   - 重启本地服务器
   - 在浏览器中刷新页面查看效果

---

### 方法 2：使用命令行批量替换

```bash
# 进入项目目录
cd /Users/deelii/code/mr-pandas-portfolio

# 创建备份（重要！）
cp assets/index--Xm2hwTR.js assets/index--Xm2hwTR.js.backup

# 使用 sed 替换文字（macOS）
# 格式：sed -i '' 's/旧文字/新文字/g' 文件名

# 示例：将 "portfolio" 替换为 "作品集"
sed -i '' 's/portfolio/作品集/g' assets/index--Xm2hwTR.js

# 示例：将 "welcome" 替换为 "欢迎"
sed -i '' 's/welcome/欢迎/g' assets/index--Xm2hwTR.js
```

## ⚠️ 重要注意事项

### 1. 备份文件
在修改前**一定要备份原始文件**：
```bash
cp assets/index--Xm2hwTR.js assets/index--Xm2hwTR.js.backup
cp index.html index.html.backup
```

### 2. 字符长度
- 压缩的 JavaScript 代码对字符长度敏感
- **尽量保持替换后的文字长度与原文字相近**
- 如果长度差异太大，可能会影响布局

### 3. 特殊字符
- 避免使用特殊字符（如引号 `"`、反斜杠 `\`）
- 中文字符通常没问题

### 4. 测试
修改后一定要测试：
```bash
# 重启服务器
双击 start.command

# 在浏览器中查看效果
访问 http://localhost:8000
```

## 🎓 高级方法（可选）

如果你需要大量修改文字，可以考虑：

1. **反编译源代码**
   - 使用工具如 `unminify` 或在线服务解压缩 JavaScript
   - 修改后重新压缩

2. **使用浏览器扩展**
   - 安装浏览器扩展动态替换文字（不修改源文件）

3. **联系原作者**
   - 获取未压缩的源代码
   - 更方便地进行修改

---

## ✅ 总结

最简单的修改方法：
1. 用文本编辑器打开 `index.html`
2. 修改 `<title>` 和 `<meta>` 标签中的文字
3. 保存并刷新浏览器

如果需要修改页面内容中的文字，建议使用 VS Code 的查找替换功能在 `assets/index--Xm2hwTR.js` 中搜索和替换。

**记得先备份！**
