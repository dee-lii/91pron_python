# 🚀 快速使用指南

## 如何打开网站？

### ⚡ 最简单的方法（推荐）

1. 找到项目文件夹中的 **`start.command`** 文件（macOS/Linux）或 **`start.bat`** 文件（Windows）
2. **双击**这个文件
3. 等待 2 秒，网站会自动在浏览器中打开
4. 享受浏览！

### ⚠️ 注意事项

- **不要直接双击 `index.html`**，这样会因为浏览器的 CORS 安全策略而无法加载
- 使用完毕后，关闭终端窗口即可停止服务器
- 服务器运行在 `http://localhost:8000`

## 为什么不能直接打开 HTML 文件？

这个网站使用了现代的 **ES6 模块**技术。浏览器的安全策略要求：

- ES6 模块必须通过 HTTP(S) 协议访问
- `file://` 协议会被 CORS 策略阻止
- 这是为了保护你的计算机安全

## 遇到问题？

### macOS 用户可能遇到的问题

**问题**：双击 `start.command` 提示"无法验证开发者"

**解决方案**：
1. 右键点击 `start.command`
2. 选择"打开"
3. 在弹出的对话框中再次点击"打开"
4. 以后就可以直接双击使用了

### 端口被占用

**问题**：提示 8000 端口已被使用

**解决方案**：
1. 找到占用端口的程序并关闭
2. 或者编辑启动脚本，将 `8000` 改为其他端口（如 `8080`、`3000` 等）
